agca·studio is an architecture studio run by two founding partners in Üsküdar, Istanbul. In urban regeneration projects we start by reading the existing fabric; we carry out architectural design in Revit within a single building information model; and we use visualisation and virtual tours as tools for experiencing a design before it is built.
